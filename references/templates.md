# Templates

Copy these into the project's `paper-orchestra/` folder. Do not edit this file per project.

## Source-evidence matrix (`02_evidence_matrix.md`)

Status values: `verified` | `partially-verified` | `unverified` | `rejected`.
Only `verified` and `partially-verified` rows may be cited in drafts.

| ID | Cite key | Full reference (as confirmed) | DOI / URL opened | Type | Claim(s) supported | Where in source | Used in | Status | Verified on | Notes |
|---|---|---|---|---|---|---|---|---|---|---|
| S01 | `lastnameYYYYword` | Authors. Title. Venue, Year. | https://doi.org/... | journal / conf / preprint / standard / docs / dataset | "Claim in your own words" | Abstract; Sec. 3.2; p. 7 | Intro, RW-2.1 | verified | YYYY-MM-DD | |
| S02 | | | | | | | | unverified | | paywalled - metadata only |

Gap list (claims with no verified source yet):

| Claim | Needed for section | Search attempted | Next step |
|---|---|---|---|

Optional CSV twin header:
`id,cite_key,reference,doi_or_url,type,claims,location,used_in,status,verified_on,notes`

## Evidence labelling in any output

```
Verified:    <statement> - [S03], results/run2.csv
Assumption:  <statement> - why it is reasonable, what would confirm it
Missing:     <what is needed> - who/what could provide it
```

## Outline (`03_outline.md`)

```

   - Hook: <macro context>                     cites: S01, S04
   - Gap: <scoped to evaluated data only>      cites: S07
   - Contributions (each maps to evidence):    data: <file>
2. Related Work
   2.1 <Cluster A> - limitation hypothesis; bridge to ours     cites: ...
   2.2 <Cluster B> - ...
3. Method
   3.1 ... (source: idea.md sec. X)
   3.2 ...
4. Evaluation
   4.1 Setup (datasets/scenarios, baselines, metrics, environment)   cites: ...
   4.2 Results  -> tab_main_results (data: results/main.csv)
   4.3 Ablation / analysis
5. Limitations and threats to validity
6. Conclusion
Appendix / artifact statement

Figures & tables:
| id | type | data source | purpose |
```
